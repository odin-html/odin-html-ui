# Theme tokens no component uses

## Objective

**Triage (2026-10-17):** later, when the theme is mapped onto Basecoat's — unused tokens are inert; the Basecoat mapping rewrites the theme anyway

`web/src/index.css` defines theme tokens that no component reads: `--color-sidebar-primary*` and `--color-selection*`, and `--chart-1` to `--chart-5`, which are never mapped into `@theme`. They are harmless, but a consumer reading the theme to restyle the library cannot tell which tokens matter.

When the theme is mapped onto Basecoat's (`UI-V-0001`, the Basecoat direction), keep only the tokens a component uses, or document why one is kept.

## Acceptance Criteria

- [ ] Every token in the theme is read by a component, or carries a one-line reason it is kept.
